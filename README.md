# odin-recipes

This is HTML first project in the Odin project.

In this project, I want to practice the following foundations in HTML:
- Elements and Tags like h1, p, strong, em or void elements like br or img
- How to use ! to create HTML Boilerplate
- How to use Cmd + / to comment
- How to use ul for unordered list and ol for ordered list
- How to insert link with a href= and image with img src=
- How to commit meaningful commit messages
